def quick_sort(arr):
    # 如果数组长度小于等于1，直接返回
    if len(arr) <= 1:
        return arr
    
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    
    return quick_sort(left) + middle + quick_sort(right)
/> 解释一下这段代码

这是一个经典的快速排序（Quick Sort）递归实现：

  • 基准选择：选取数组中间位置的元素作为 pivot。
  • 分区：通过列表推导式将数组分为 left（小于基准）、middle（等于基准）和 right（大于基准）。
  • 递归：递归处理左右两部分，最后合并结果。
