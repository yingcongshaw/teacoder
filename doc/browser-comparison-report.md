## 一、总体布局对比

## 三、视觉风格差异

### 3.1 整体风格

| 维度 | AICoder | TeaCoder |
|------|---------|-----------|
| **UI 框架** | 自定义（类似 VS Code） | Ant Design 6 + TailwindCSS |
| **色调** | 深色主题为主，高对比度 | 支持 dark/light，但对比度较低 |
| **图标** | 自定义图标（更精致） | Ant Design 图标（通用） |
| **字体** | 系统默认（更紧凑） | JetBrains Mono / system-ui |
| **间距** | 紧凑（类似 IDE） | 较宽松（Ant Design 默认） |
| **圆角** | 小圆角（2-4px） | 较大圆角（Ant Design 默认 6px+） |

### 3.2 具体组件差异

| 组件 | AICoder | TeaCoder |
|------|---------|-----------|
| **按钮** | 扁平，无阴影，hover 微亮 | Ant Design 默认样式（有阴影） |
| **输入框** | 细边框，聚焦时高亮 | Ant Design 默认样式 |
| **下拉菜单** | 紧凑，无多余间距 | Ant Design 默认样式（较宽松） |
| **标签页** | 类 VS Code 风格（底部边框） | 简单样式（背景色区分） |
| **侧边栏** | 树形结构，图标+文字 | 分组折叠，图标+文字 |
| **弹窗** | 圆角小，阴影轻 | Ant Design 默认（圆角大，阴影重） |
| **状态栏** | 紧凑，信息密度高 | 较宽松 |

## 五、主要差距与建议

### 5.1 高优先级差距（影响用户体验）

1. **主题系统薄弱**
   - 差距：仅 2 套主题 vs AICoder 的 10+ 套
   - 建议：至少增加 3-5 套预设主题（如 VS Code 的 Dark+、Light+、Monokai、Dracula 等）

2. **缺少 Onboarding 流程**
   - 差距：无用户协议、首次引导
   - 建议：添加首次启动弹窗（用户协议 + 简要引导）

3. **设置页面不足**
   - 差距：仅 4 个实际页面 vs AICoder 的 18+ 页面
   - 建议：按优先级补充 Codex/Gemini/OpenCode 设置、快捷键、网络设置

4. **视觉风格差距**
   - 差距：Ant Design 默认样式 vs AICoder 的精致自定义风格
   - 建议：自定义 Ant Design 主题（token 覆盖），减小圆角/阴影，增加紧凑模式

### 5.2 中优先级差距

5. **Profile 管理未实现**
   - 当前为菜单占位，需要实际 CRUD 界面

6. **费用统计未实现**
   - 当前为菜单占位，需要图表展示

7. **缺少仪表盘**
   - 底部面板缺少 Token 统计图表

8. **窗口控制按钮**
   - Tauri 应用需要自定义窗口控制（最小化/最大化/关闭）

### 5.3 低优先级差距

9. **远程访问/SSH**（v0.1 边界外）
10. **MCP 接入**（v0.1 边界外）
11. **同步功能**（v0.1 边界外）
12. **数据管理**（v0.1 边界外）

## 七、总结

### 7.1 已完成（Week 1 + Week 2）

- ✅ 基础设置系统（通用/终端/Claude/关于）
- ✅ 侧边栏搜索/排序/过滤/折叠/收藏
- ✅ 标签页右键菜单（重命名/复制/移动/属性/关闭）
- ✅ 新建会话高级选项（环境变量/启动参数）
- ✅ 底部面板框架（文件树/Git/指令/任务）
- ✅ 快捷输入按钮（继续/建议/采纳/提交）
- ✅ 模型切换 + 思考强度（状态栏）

### 7.2 主要差距

1. **视觉风格**：Ant Design 默认样式 vs AICoder 的精致自定义风格
2. **主题系统**：2 套 vs 10+ 套
3. **设置页面**：4 个实际页面 vs 18+ 页面
4. **Onboarding**：无首次引导
5. **Profile/费用**：菜单占位，未实现内容

### 7.3 下一步建议

1. **视觉优化**：自定义 Ant Design token，减小圆角/阴影，增加紧凑模式
2. **主题扩展**：增加 3-5 套预设主题
3. **Profile 管理**：实现 CRUD 界面
4. **费用统计**：实现图表展示
5. **Onboarding**：添加首次启动引导
