# TeaCoder vs AICoder 功能差异分析与后续开发规划

> 生成日期：2026-08-04
> 对比基准：AICoder 截图（image/ 目录下 27 张功能截图）
> 当前版本：TeaCoder v0.1 MVP（开发中）

---

## 一、总体差异概览

| 维度    | AICoder（参考目标）     | TeaCoder（当前实现）   | 差异等级 |
| ----- | ----------------- | ----------------- | ---- |
| 界面复杂度 | 极高，专业 IDE 级别      | 中等，基础管理客户端        | 🔴 大 |
| 功能数量  | 50+ 个独立功能模块       | ~15 个核心功能         | 🔴 大 |
| 设置深度  | 7 大类 20+ 子页面      | 3 个标签页            | 🔴 大 |
| 终端集成  | 深度集成，多面板          | 基础 PTY + xterm.js | 🟡 中 |
| 主题系统  | 10+ 套内置主题         | 深色/浅色/跟随系统        | 🟡 中 |
| 费用追踪  | 仪表盘 + 模型切换 + 思考强度 | 基础状态栏数字           | 🟡 中 |

## 二、六大功能领域详细对比

### 2.1 首页与登录流程

#### AICoder 已实现

- **用户协议弹窗**（图 1）：首次启动显示用户协议，需同意后才能进入
- **首次登录指引**（图 2.1-2.3）：三步引导流程，介绍核心功能
- **顶部窗口控制栏**：设置、最大化、最小化、关闭按钮
- **左右布局（约 2:8）**：左侧项目/会话树，右侧终端内容区

#### TeaCoder 当前状态

- ❌ 无用户协议弹窗
- ❌ 无首次登录指引
- ✅ 有顶部栏（但无窗口控制按钮）
- ✅ 左右布局（侧边栏 + 主内容区），比例约 1:4（需调整）

#### 差异分析

| #   | 功能     | 状态     | 优先级 | 备注                        |
| --- | ------ | ------ | --- | ------------------------- |
| 1.1 | 用户协议弹窗 | ❌ 缺失   | P2  | 首次启动检测，localStorage 标记已同意 |

| 1.4 | 布局比例调整 | 🟡 需优化 | P2  | 侧边栏应更窄（~200px），主区域更宽      |

### 5.3 主题系统建议

当前只有 `dark/light/system`，建议：

1. 扩展 `theme` store 为 `theme` + `themePreset`
2. 预设主题存储为 JSON 配置（主色、背景色、强调色）

## 六、风险与建议

### 6.1 范围风险

AICoder 功能极其丰富（50+ 模块），TeaCoder v0.1 不可能全部实现。建议：

- **v0.1 聚焦**：PTY 终端 + 会话管理 + Profile + 费用追踪 + 基础设置
- **避免功能蔓延**：严格按照优先级矩阵执行

### 6.2 技术风险

- **AntD + TailwindCSS 冲突**：需严格遵循 CLAUDE.md 规范，Tailwind 仅用于布局
- **xterm.js 性能**：大量输出时需限制 scrollback
- **Tauri IPC 延迟**：底部面板实时数据需考虑性能

### 6.3 与 AICoder 的差异化建议

不必完全复制 AICoder，TeaCoder 应突出自身优势：

- **多工具统一管理**（AICoder 似乎各工具独立）
- **零额外 Token 开销**（PTY 直通是核心差异）
- **本地优先**（全本机存储，隐私友好）
- **费用追踪**（AICoder 虽有但 TeaCoder 可做得更专业）
